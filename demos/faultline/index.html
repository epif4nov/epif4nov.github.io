The engineering idea

Quorums must overlap.

A write completes after W = 2 acknowledgements. With R = 1, a read can miss both updated replicas. With R = 2, every read quorum intersects every write quorum because R + W > N.

This model checks a completed-write version floor, not full linearizability. Recovery preserves local data; there is no repair, consensus, or real network.
