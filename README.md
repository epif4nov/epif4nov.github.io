# epif4nov — developer portfolio

Статическая витрина проектов универсального junior-разработчика: Python, C#, C++, backend, алгоритмы и данные.

## Локальный просмотр

```sh
python -m http.server 8000
```

Откройте `http://127.0.0.1:8000`. Сайт не требует Node, сборки, внешних шрифтов или API.

## Содержание

- `index.html`, `assets/` — портфолио с фильтрами проектов.
- `demos/faultline/` — работающая визуализация из [Faultline](https://github.com/epif4nov/newRep), исходная версия `ef58d084ed265f66ca98646df97de20c538e3453`. Лицензия MIT приложена в каталоге демо. Обновляйте `index.html` и `demo.js` из `web/` исходного проекта вместе.
- `history/index.html` — прежняя историческая страница, сохранённая без изменений. Её внешние ресурсы и старые функции не входят в проверку нового портфолио.

При изменении содержания сверяйте утверждения с реальными репозиториями. Указывайте требования к запуску, учебные источники и ограничения проектов.

## Публикация

GitHub Pages должен публиковать корень ветки `main`. Если Pages отключён или настроен иначе, включите эту опцию в Settings → Pages. Сам push не доказывает, что сайт опубликован.

Предложенные bio, закрепления и описания репозиториев собраны в [PROFILE_SETTINGS.md](PROFILE_SETTINGS.md); эти настройки аккаунта не применены через Git.
